# ITW PPF 依工聚合小程序 — 网页交互预览

**在线预览：[https://lexiejl.github.io/itw-ppf-preview/](https://lexiejl.github.io/itw-ppf-preview/)**

这是 ITW PPF 依工聚合微信小程序的网页交互原型，用于在没有微信开发者工具的情况下快速预览页面结构、视觉设计与交互逻辑。

## 说明

- 单文件 HTML/CSS/JS 原型，模拟小程序的五个一级导航（聚·视界 / 聚·前沿 / 聚·应用 / 聚·伙伴 / 聚·商城）
- 包含真实品牌 logo、官网宣传图（来自 itwppfasia.com）与文档中的真实业务内容
- 会员注册、经销商申请、样品申请等流程均可在浏览器中直接体验
- 正式的微信小程序代码见 [itw-ppf-miniprogram](https://github.com/LexieJL/itw-ppf-miniprogram) 仓库
